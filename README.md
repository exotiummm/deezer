# **Deezer Search**

An easy desktop app to search music using Deezer API!

---

## About

The app provides:
- Artists, albums and tracks search
- Album's tracklist display
- Ability to download and listen to 30-second long track previews

---

## Using

- [Deezer API](https://developers.deezer.com/api)
- C# / Windows Forms
- Newtonsoft.Json

---

## How to use

1. Download repository
2. Open `deezer.slnx` in Visual Studio
3. Press `F5`
